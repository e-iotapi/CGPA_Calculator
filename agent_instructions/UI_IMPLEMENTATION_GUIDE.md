# UI implementation guide (Builder 2 and its subagents)

Scope: U1–U15 of `BUILDOUT_PLAN.md`. Read with `UI_CHANGES_BRIEF.md` (owner specifics), `UI_MAP.md` (tags), `PROPOSED_FEATURES.md`. Store signatures come from `BUILDOUT_CONTRACTS.md`, which did not exist when this was written: every store call below is marked "per contracts" and names the plan's B item. Build against `FakeFirebaseFirestore`; the backend must match the contract exactly.

Rules above all else: **staging is the spec**. Only parts tagged NEW / CHANGED / REMOVED in `UI_MAP.md` change. The 36 untagged screens (brief §0.1) get no code change. DEFERRED = do not build. No restyling, no new widgets where the kit has one. Section references: `docs/ARCHITECTURE.md` = "DA", `agent_instructions/ARCHITECTURE.md` = "AA".

## Part 1. Invariants new UI must keep

Each line: rule; where it lives; the guard.

1. **Startup path.** Nothing networked before `runApp`; only Firebase init, Hive open, sign-in check, `Sync.init`. Roles, catalogue refresh, prefetch, live socket, analytics all run after the first frame (`lib/main.dart` `startApp`, `unawaited(...)`, `addPostFrameCallback`). `web/index.html` starts Firebase/Auth with the page, preloads fonts and SDK, loads gtag on `flutter-first-frame`, caps `devicePixelRatio` at 2, unpans the page on touch (UT-3). New screens never add an `await` to `main()`/`startApp`; any new Hive box is opened in the existing `Future.wait` and registered per AA §14.4 (box lists in `lib/sync.dart`, `cache_boxes.dart`). Guards: `test/env/index_html_test.dart` (SDK version, fonts == manifest, options == Dart, gtag after first frame), `test/core/cache_boxes_test.dart` (no cache box in `Sync._boxes`). Tour/calendar code must not touch `main.dart`.
2. **Deferred admin.** Every staff screen is built only through `_admin(path, () => admin.X(), may)` or `_deferred(() => admin.X(...))` in `lib/app/router.dart`. Student code (`lib/features`, `lib/home_page.dart`, `lib/shared`) must never import `package:cgpa_calculator/admin/...` except via `admin.dart deferred as admin` in the router. A screen both roles need (the link sheet, U4/U11) is extracted to `lib/shared/` or `lib/features/` and imported by `lib/admin`, never the reverse. Guard: `test/core/nospin_test.dart` (`DeferredPage` with `loaded: true` draws in the first frame), `test/app/routes_test.dart`. Risk K9.
3. **Cache first, no spinner on revisit.** Stores read through `cacheFirst` (`lib/core/cache/cache_first.dart`: `key`, `version: await markerOf(db, campus, Paths.x)`, `maxAge`, `encode`, `decode`) and expose a synchronous `peek*` twin built on `peekCache(key, decode)`. Screens use `Loaded<T>(load, cacheKey, peek, builder|gated)` (`lib/admin/widgets.dart` 363–490; also used by student screens). `cacheKey` carries every scope (campus, programme list, email, filters that change the data). Screens with writes use `gated:` (writes off while `saved == true`). `Loaded` shows a spinner only when there is no session cache and no peek; a failed refresh keeps the saved copy and (gated) shows a snackbar with Try again. Live search is not cached. Add a `forget('<prefix>')` for every write that changes a cached read. Guards: `test/ui/nospin_screens_test.dart`, `test/admin/loaded_cache_test.dart`, `test/core/nospin_test.dart`. Risk K7. Extend `nospin_screens_test.dart` for each new keyed screen.
4. **Prefetch levels.** A new screen's data is registered in `lib/app/prefetch_levels.dart` (Builder 2 owns this file): L2 = More hub, Reviews, Representatives, Resources, and anything a Home tab needs (Calendar timetable, U14); L3 = sub-pages; L4 = admin, one request at a time (approvals, claims, gate switch). Jobs are `_job(() => store.call(...))`; failures are dropped; the run happens once per session, 2 s after first frame, only for markers that moved. Guard: `test/core/prefetch_test.dart`. Add a job and assert it appears in the right level.
5. **Roles and routing.** `leaveRoleOutside` (`router.dart:49`) keeps a role only on `/admin`, `/maintain`, `/roles`, `/campus`; any other location makes president/CR a student and owner the owner again. Staff screens (approvals, claims, gate switch, anything needing a role) live under `/admin` or `/maintain/:campus/:dept/...`. Student screens (Contribute, Leaderboard, Apply, Tour) live outside them and use the grant, never working-as. Route guards are a courtesy (rules decide). New top-level segment under Home needs a `landing/_redirects` line (`/calculator/x` and `/calculator/x/*` when nested); `test/app/routes_test.dart` fails otherwise. Route constants and `openRoute` live in `lib/app/routes.dart`; use `openRoute(context, Routes.x, () => Page())` so bare widget tests work. Guards: `test/app/leave_role_test.dart` (extend with each new path), `routes_test.dart`. Risk K8.
6. **Nav.** `AppNav` (pill < 1100 px, rail at/above) through `ResponsiveScaffold`; never `BottomNavigationBar` (AA §14.7). The pill is removed while `viewInsetsOf.bottom > 0`. Home hard-codes More as index 4 (`home_page.dart:113`) and `selectedprofile = index + 1`; U3 maps destinations by id. Legacy: edit `home_page.dart` by hand, never `dart format`. Guards: `test/shared/responsive_test.dart`, `nav_screenshots_test.dart`, `home_rebuild_test.dart`. Risk K4.
7. **Theme.** Rebuild goes through `themeVersion` (`script.dart:383`, listened in `main.dart:376`). Home has no `Theme` of its own (comment at `home_page.dart:104`); a copy there stops switching. New widgets read `AppPalette.of(context)`, `TypeScale`, `Space`, `Radii`, `Sizes` from `lib/app/theme/tokens.dart`. No hard-coded colours. Guards: `test/theme/*`, `test/perf/theme_switch_test.dart`.
8. **Widget kit only.** Compose from `lib/shared/widgets` (PageFrame, PageHeader, BottomAction, PrimaryButton, AppCard, CardRow/CardDivider, SegmentedPair/SegmentedTrack, SearchBox, Notice, OfflineStrip, confirmDialog/AppDialog/DialogAction, CircleIconButton, OutlinedPill, PillButton, CountPill, CountBadge, TagBadge, CodeBadge, AppTextField/CompactField/FieldLabel, StatCard, DashedOutline, SliverRowGroup) and `lib/admin/widgets.dart` (Loaded, problem(), SectionLabel, RowGroup, NavRow, ScopePills, ChoicePills, Note, AmberPill, InkCard, IconTile, MiniChip, TextLink, SelectRow, TierTag). A new screen is a copy of an existing screen's structure. If a widget is truly missing, ask the controller: `lib/shared/widgets/**` is Builder 2 controller-owned. Guard: `test/shared/widgets_test.dart`, `test/ui/board_shots_test.dart`.
9. **Keyboard (UT-3).** Every new input sits in a `ResponsiveScaffold`/`PageFrame` page, or an `isScrollControlled` sheet padded by `MediaQuery.viewInsetsOf(context).bottom` (examples: `add_course_sheet.dart:180`, `edit_course_sheet.dart:124`, `dept_resources.dart:162`). Never `MediaQuery.of`; never resize the whole page. Guards: `responsive_test.dart:199`; add a widget test per new sheet with `t.view.viewInsets = FakeViewPadding(bottom: 300)` asserting the field stays visible. Risk K13.
10. **Semantics and sizes.** Every tappable is ≥ 44 px (`Sizes.minTouch`), wrapped in a labelled `Semantics`/tooltip; rows are one semantic container; headers use `Semantics(header: true)`; nothing overflows at 320 px width or 200 % text; a 60-character title ellipsizes; light and dark render (AA §15). Guards: `test/settings/semantics_tap_test.dart`, `test/roles/strip_semantics_test.dart`, `python3 agent_toolchains/ui_check/ui_check.py run`.
11. **Performance.** No `Opacity` (use `withValues(alpha:)` colours; `test/perf/no_opacity_test.dart` allow-list). Lists of more than ~12 rows are lazy (`ListView.builder`/slivers, `SliverRowGroup`). Self-animating or static-over-scroll widgets get a `RepaintBoundary` (`test/perf/repaint_boundaries_test.dart`). Use `MediaQuery.sizeOf`/`viewInsetsOf`/`paddingOf`, not `of`. No Hive/settings writes inside `build` (`test/perf/no_writes_in_build_test.dart`). Home never rebuilds fully for an overlay (PERF-02 area; `home_rebuild_test.dart`). Risk K14.
12. **Fonts.** Every string literal in `lib/` must be inside `tools/font_chars.txt` (the glyph subset; comma-separated `U+XXXX`), else it falls back to a downloaded font. New glyphs (★, ·, –, "Electives") are added there and the fonts re-subset with `tools/subset_fonts.sh`. Builder 2 controller owns the file. Guard: `test/perf/font_chars_test.dart`. Risk K6.
13. **wasm numbers.** JS numbers arrive as `double`; read with `as num` (then `.toInt()`), never `as int` (a throw after first frame blanks the app; DA §12). Applies to Firestore maps (`marks`, `points`, `ts`, `v` markers). Review with `grep -n "as int" <changed files>`. Risk K18.
14. **Hive under fake time.** UI-triggered Hive writes stall in widget tests. Unit-test storage in plain `test()`; give widget tests in-memory stores. Pre-seed a Hive cache inside `await t.runAsync(() async { Hive.init(tmp); await openSharedCache(); await sharedCacheBox!.put(...); })` (`test/ui/nospin_screens_test.dart:21`), then pump. Never legacy `Course` adapter (K5); new device data goes in new boxes.
15. **Formatting.** `dart format` only files you create. Never on `main.dart, home_page.dart, script.dart, course.dart, mastercourselist.dart, sync.dart, settings_page.dart`, `main_ui_extension.dart` (CRLF) or any file formatted differently at HEAD (AA §14.2). `verify.py` compares the analyzer to `tools/analyze_baseline.txt`: zero new infos (K19).
16. **Errors, offline.** Every new screen has: load failure with `Loaded`'s built-in `Notice(warning: true)` + Try again, `problem(e)` for write errors (never raw exceptions), `OfflineStrip` where writes are possible, denied (`permission-denied` -> `problem()` copy), and a failed-write snackbar/inline notice. See U15.
17. **Sync of prefs.** User prefs sync through `settingsBox` -> `users/{uid}`; values JSON-encodable (no `DateTime`, AA §14.3); 500 KB cap (AA §14.5). Rules whitelist `prefs.offshootHidden`/`prefs.tourSeen` only (K12).
18. **Test hooks.** `?as=<key>` signs in test accounts (staging/emulator builds only; `lib/core/env/test_sign_in.dart`, keys in `tools/test_env/accounts.json`, new ones from B9). Password only from `STAGING_PASSWORD`; never print it. Never commit `bugs/`, `bug_*.md`, `tools/course_reviews_out/`, `tools/perf_out/`, `.superpowers/`, `tools/e2e/{perf_run,retest,trace_run}.mjs`, any `*.pdf`.

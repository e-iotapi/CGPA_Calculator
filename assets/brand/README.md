# Pointer brand

The Tassel mark (logo concept 04, chosen on the UI Directions board). In the
app it is `lib/shared/widgets/pointer_mark.dart`; these files are the same
drawing for everything outside the app.

| File | Use |
|---|---|
| `pointer-logo.svg` | The full logo: the mark over a faded cap band. Large sizes |
| `pointer-mark.svg` | The mark alone, ink (`#17170F`), on light backgrounds |
| `pointer-mark-yellow.svg` | The mark alone, yellow (`#F2E7A8`), on ink |
| `pointer-tile-light.svg`, `-ink.svg`, `-mint.svg` | The three square tiles from the board |
| `pointer-icon.svg` | The installed-app icon (mint on ink), the source of `web/icons` |

Colours: ink `#17170F`, mint `#B4DED0`, yellow `#F2E7A8`, light `#F2F2EF`.
